01

principles

The Zune rejected the glossy, button-heavy look of its era and leaned into being authentically digital — flat, typographic, alive in motion. v5 continues to protect the recognizable DNA while removing the remaining friction points that made the original hard to use at scale.

i

content before chrome

The story is the interface. Strip frames, borders and decorative panels until only the words, the image and the single accent remain — but never strip the affordance that tells you something is tappable.

ii

type is the ui

One variable typeface; hierarchy is built from weight and scale alone. The lightest weights are reserved for large sizes; anything you must read to function carries more weight.

iii

bleed honestly

Headlines can still run past the margin — but only on words the reader already knows. The unique, informative part of a headline is never the part that gets clipped.

iv

dark, quiet canvas

Near-black backgrounds, generous negative space. Color is rationed — one accent owns one region. The accent is now a tonal system so states never need a border.

v

motion has meaning — and yields

Fast, fluid, directional. And when a reader asks for less, the system keeps its structure and drops the movement.

02

fallback stack — for when the variable font doesn't load

font-family: 'Roboto Flex', 'Segoe UI', system-ui, -apple-system, 'Helvetica Neue', Arial, sans-serif;

Humanist-sans on every platform, so the silhouette survives a failed load. Fallback faces carry no thin display cut, so the display role drops to weight 300 rather than 250 — the masthead never thins into invisibility:

@supports not (font-variation-settings: 1) { .giant, .s-display, .bleed-head { font-weight: 300; } }

responsive scaling — one ramp, every screen

Every display size is a clamp(min, fluid, max), so a 72px page title lands near 38px on a 320px phone with no breakpoint. The min is the legibility floor, the max is the desktop voice, and the vw term interpolates between them. Body and labels hold fixed sizes — only display type scales.

04

layout

Beneath the three signature structures — panorama, pivot, and tiles — sits an ordinary, strict skeleton: one spacing scale, a twelve-column grid, four breakpoints, and a vertical rhythm. The drama is in the type and motion; the bones are boring on purpose.

spacing scale — a 4px base, every gap and pad drawn from it

4 · 3xs
8 · 2xs
12 · xs
16 · sm
24 · md

Never an arbitrary value. Component interiors lean on 16–32; section rhythm on 64–128. Vertical rhythm: stacks come from the scale, body line-height holds at 1.55, section padding is clamp(70px, 12vh, 140px).

grid & breakpoints

A 12-column grid, 24px gutter, and the --gut margin clamp(20px, 5vw, 80px). Most grids are auto-fit minmax() rather than fixed columns, so they reflow with no per-breakpoint code — the four tiers are guardrails, not switches.

07

motion

Fast, fluid, directional. Short durations and a snappy ease. The big difference in v5: motion is part of the brand but not a requirement. When reduced-motion is requested, the structure stays and the movement stops.

slide

Panes enter from the offscreen edge. Panorama and pivot move horizontally.

stagger

Items rise and fade in sequence on load.

turnstile

Content rotates in around its leading edge.

micro lift

Small upward shift + shadow on interactive cards.

content push

Elements slide forward on interaction.

Motion tokens: --ease: cubic-bezier(.2,.88,.2,1)  •  --dur-fast: 160ms  •  --dur-base: 260ms  •  --dur-slow: 380ms

reduced-motion mapping — what each animation becomes

default animationreduced-motion behaviour
pano / pivot slideinstant pane swap, no translate
scroll reveal (fade + rise)appears in place, fully visible
stagger cascadeall items appear at once
parallax ghoststatic, no scroll-linked motion
looping motion demosfrozen on a representative frame
micro-lift · push (hover)color / weight change only, no transform
weight-on-focuskept, applied instantly
reduced motion

Under @media (prefers-reduced-motion: reduce) all slides, parallax, looping demos and staggered reveals are disabled. Content simply appears. Nothing becomes unreachable.

08

do · don't

do
  • Let one vivid accent own each section.
  • Build hierarchy from one variable typeface.
  • Reserve thinnest weights for large sizes.
  • Bleed only words the reader already knows.
  • Give interactive elements a resting state that reads as live.
  • Pair every category color with a word.
  • Use black ink on accent fills (≥ 5.7:1).
  • Ship compact mode and reduced-motion path for every component.
don't
  • Add gradients, bevels, glass or drop-shadows.
  • Clip the informative part of a headline.
  • Set body or labels in the lightest weights.
  • Hide content behind a horizontal pan with no fallback.
  • Rely on hover alone to reveal interactivity.
  • Encode meaning in color only.
  • Put white text on the light accents.
  • Let motion run with no reduced-motion escape.

Every value in this manifesto resolves to a named token. Six families — color, type, space, motion, state, breakpoints — exported as plain CSS custom properties and as JSON, so the words and the build share one source of truth.
